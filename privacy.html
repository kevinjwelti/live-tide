Live Tide

Privacy

Live Tide is a tide clock. It does not have accounts, and it does not sell information.

The website

The page remembers the beach and the scene you picked, in this browser only (local storage on your device). It asks the public NOAA tide service, and sometimes a tide file hosted with this site, for the numbers it draws. Those requests include the usual connection details a web server sees, such as an IP address.

“Near me” on the beach list uses your location once, and only after you tap it. The TV app does not show that control and does not ask for location.

The TV app

The Fire TV and Google TV app is a full-screen window onto this same page. It does not add analytics, advertising, or an account. It keeps a copy of the page on the device so a short network outage does not blank the screen.
